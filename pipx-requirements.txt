# install.sh, install.ps1, and .github/workflows/test-install.yml all install
# pipx with `pip install --require-hashes -r pipx-requirements.txt` instead of
# a bare `pip install pipx`, so a compromised/typosquatted PyPI upload can't
# get pulled in silently.
#
# To bump the pinned pipx version, regenerate this whole file (pipx's
# resolved dependency set can change between releases) rather than
# hand-editing one line. Easiest with pip-tools:
#   pip install pip-tools
#   pip-compile --generate-hashes --output-file=pipx-requirements.txt - <<< "pipx==<new-version>"
# or by hand from https://pypi.org/pypi/pipx/json (and the same for each of
# its runtime dependencies) using the sha256 digests listed under "urls".
